# SakuLoca 利用ガイド

正式版1.0.1の利用ガイドです。アプリ本体は無料・オープンソースで配布します。

## インストールと初回設定

初期サポート対象はWindows 11 64bit、GPUの確認済み構成はRTX 2070（VRAM 8GB）です。他GPU、Windows 10、ARM/32bitは初期サポート対象外です。CPUは4スレッドの診断と少数人工画像の解析を確認しましたが、大量写真での実用速度は未評価です。モデルは約462 MiB、AIキャッシュ最大1 GiB、サムネイル最大512 MiB、検索データのために保存先に2 GiB以上の空きを推奨します。原写真の容量は別です。

NSISセットアップexeを起動し、インストール先を選びます。通常は管理者権限不要です。Python/Rust/Node/Visual Studioのインストールは不要で、Worker実行環境を同梱します。WebView2不足時はMicrosoft公式セットアップを利用します。オフラインの場合は[Microsoft公式WebView2配布](https://developer.microsoft.com/microsoft-edge/webview2/)からRuntimeを別途用意します。

初回画面でPC診断、モデル選択、保存先、写真フォルダー、背景設定、初回解析の順に案内します。途中で閉じても次回に同じ手順から再開できます。既存の登録フォルダーがある利用者には初回画面を強制しません。

既存の`.litertlm`はコピーせず参照して使えます。モデルがない場合は、容量・保存先・配布元・Apache-2.0条件を確認し、明示同意後に取得できます。Google公式ガイドが指定する[LiteRT Community配布](https://huggingface.co/litert-community/embeddinggemma-2-740m-litert-lm)の固定revisionを使用し、公開LFS SHA-256で検証します。取得は停止/再試行/途中再開できます。SHA不一致の途中ファイルは利用しません。異なる同名ファイルは上書きしません。オフラインでは既存ファイル指定を使用してください。

## 写真の登録と検索

「フォルダーを追加」で対象だけを登録します。サブフォルダーも対象で、JPEG/PNG/WebPを扱います。ドライブ全体やモデル/検索データを含む親領域は登録できません。リンク/ジャンクションを追跡しません。登録解除は写真を消しませんが、そのフォルダーだけに所属する検索インデックスは除外します。

「差分更新 / 解析」で追加/変更された写真を解析します。同じモデルの保存済み写真を再解析しません。「海辺の風景」「赤いりんご」のような言葉や「画像で探す」で指定した参照画像で検索します。AIの類似度は正解率や確信度ではありません。細かな人物識別、文字の完全一致、撮影場所の断定は保証しません。ファイル名・形式・更新日で絞れます。

結果は60枚ごとのページです。意味検索は対象全体を近い順に並べ、1,001位以降もページで表示できます。同点は登録ID順です。フィルター変更時は該当写真全体から順位を計算します。グリッド/リストを切り替え、写真をクリックするとプレビュー、拡大/縮小、元ファイル起動、Explorerでの選択ができます。Ctrl+Kで検索欄、F1でヘルプ、Escでダイアログ、Ctrl+Wでウィンドウを閉じます。Ctrl+Wも×と同じ背景設定に従います。元写真の編集・削除機能はありません。

## 解析とバックグラウンド

背景実行は既定OFFです。OFF時のウィンドウの×は保存して完全終了します。ON時の×はトレイへ格納して、解析を継続します。GPU/CPU使用状況は画面下部とトレイのツールチップで確認できます。トレイからウィンドウ再表示、一時停止、差分解析/再開、完全終了を選べます。

「一時停止」は処理中の1枚の保存後に止まり、保存済み結果は保持します。「完全終了」はWorkerを停止してアプリを終了します。異常終了時は次回に未完了だけを再開できます。再起動後の自動再開は設定で明示許可した場合だけです。Windowsログイン時の起動も既定OFFです。背景実行を許可した場合にウィンドウを表示せず起動できます。

通常モードは既存の少数先読みを使います。低負荷モードは写真の間に待機時間を設けます。アイドル限定はWindowsで120秒操作がないときに次の写真を処理します。処理中の1枚は中断しません。差分自動更新は設定した間隔（最低5分）で対象を再走査します。GPU負荷の動的測定や別アプリ優先度制御は未実装です。

## 保存場所と容量

設定でモデル、本体SQLite、サムネイル、AIキャッシュ、空き容量を分けて確認できます。AIキャッシュ削除は次回のモデル読み込みを遅くしますが、モデル/検索ベクトル/写真は保持します。AIキャッシュ1 GiB、サムネイル512 MiB上限を維持します。

保存先変更は解析/取得を停止してから空の移行先を選びます。その下のLocalPhotoSearchDataへコピーし、SQLite整合性・ファイルのSHA-256を確認した後に保存先設定を切り替えて終了します。次回起動で新しい領域を使います。元領域は残します。失敗時も元を削除しません。WebView2の一時表示データは移行後に再生成し、表示テーマは再設定が必要になる場合があります。環境変数MEDIA_SEARCH_DATA指定の起動では保存先を変更できません。

モデルだけ別の場所へ移す場合はアプリ外でコピーし、「既存モデルを選択」で新しいファイルを指定します。同一内容なら既存ベクトルを再利用できます。異なるモデルは別プロファイルになり、解析が必要です。勝手に全件再解析しません。

## エラーと復旧

- モデルなし: 既存モデルを選択するか確認後に取得。
- GPU失敗: ドライバー/モデルを確認し、CPUへ変更して診断。別GPUの対応を保証しません。
- Worker停止: 設定のWorker再起動で復旧。保存済み検索データは残ります。
- 空き容量不足: 別保存先または容量確保後に再開。64 MiB未満で新しい解析ジョブを開始しません。
- 未接続: 外付け/ネットワークドライブを再接続して差分更新。接続失敗で既存ベクトルを消しません。
- 壊れた画像/権限不足: エラー一覧で対象を確認し、権限や元画像を別途確認して再試行。

技術ログは設定から開けます。外部に自動送信しません。ログにはランタイムやローカルパスが含まれることがあるため、共有前に内容を確認してください。

## 手動更新とアンインストール

トレイの完全終了後に新しいセットアップを実行し、同じインストール先を選びます。設定・SQLite・モデルはアプリ本体と別に保持します。実行中のアプリがあれば更新/削除を拒否します。更新に失敗したら完全終了を確認し、同じセットアップを再実行してください。設定から署名付き更新を確認し、変更内容を見て取得・導入できます。起動時の確認は無効化できます。Windows Authenticode署名はありません。

Windowsの設定からアンインストールできます。写真、検索データ、モデルは削除しません。ログイン起動の登録だけ解除します。再インストールは保存先ポインターを再利用します。ユーザーデータ削除はアプリが勝手に行いません。必要なら保存場所を確認し、アプリ完全終了後に利用者が明示的に整理してください。

## プライバシーと外部通信

写真・検索文・ベクトルはローカル処理です。ローカルAPI待受ポートはなくstdin IPCです。外部通信は確認したモデル取得、Microsoft WebView2/Visual C++ Runtime導入、明示的に開いた公式ページです。写真/検索語の送信、広告、テレメトリーは実装していません。OS/ブラウザー/WebView2自体の通信は各提供元の設定に従います。

## Microsoft実行環境と不足時の復旧

アプリ本体はユーザー単位の導入です。Windows 10/11のUCRTを利用し、開発PCから収集したOS DLLを個別同梱しません。WorkerにはMicrosoft Visual C++ v14 x64（14.44以降）が必要です。不足時には確認後に[Microsoft公式パッケージ](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)を取得し、Microsoft署名・x64製品・版を確認して公式導入画面を開きます。取得約25MiB、導入用約100MiBの空きを確保してください。共通Runtimeの導入には管理者確認が必要になる場合があります。アプリのためだけに開発ツールを導入する必要はありません。

失敗したら再試行または公式VC_redist.x64.exeを別途導入し、アプリのセットアップを再実行できます。Microsoft Runtimeが再起動を要求した場合は作業を保存して手動再起動後に再実行します。勝手にPCを再起動しません。アンインストールで共通Microsoft Runtimeを削除しません。

WebView2の公式小型Bootstrapperはアプリのセットアップに同梱します。Runtime本体の取得には通信が必要です。オフラインでは公式x64 Standalone Installerで準備して再実行してください。クリーンPC試験、Runtime不足時の実導入画面、実ログイン/スリープ/再起動は未完了です。

WebView2 RuntimeにはMicrosoftの独自利用条件があります。インストーラーの同意画面と `licenses/native/WebView2/RUNTIME_EULA.html` に公式全文を収録しています。SDKのBSDライセンスとは別です。WebView2にはMicrosoft Defender SmartScreenが含まれ、Microsoftの[プライバシー声明](https://aka.ms/privacy)と[Edge Privacy Whitepaper](https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen)で説明される利用者情報を収集・Microsoftへ送信する場合があります。Runtimeの診断・自動更新通信を、アプリ自身による写真・検索語の外部送信と混同しないでください。
