# Local Photo Search 1.0.0-dev.1

2026-10-10のローカル開発版。v0.1.1（7365489）から継続開発したものです。公開・Push・v1.0.0-rc.1の作成は行っていません。

## 主な変更

- 初回案内8段階、途中手順の保存、既存モデルの参照、同梱実行環境の診断、別プロセスによるGPU/CPU実行診断。
- 明示同意後の公式モデル取得、固定revision/サイズ/SHA-256検証、進捗・停止・再試行・Range再開。同一モデルは再取得しません。
- 許可制のトレイ常駐、閉じる/格納/一時停止/完全終了の分離。親とWorkerの単一構成を維持し、終了時の保存と子プロセス管理を強化。
- オプトインのWindows自動起動、非表示起動、未完了の自動再開、低負荷、アイドル限定、定期差分更新。
- モデル/背景/容量/動作環境/エラーの設定カテゴリ、容量の種類別表示、エラー一覧と再試行、Worker再起動、日本語ヘルプ、Ctrl+K/F1/Ctrl+W。
- コピー方式の保存先移行。SQLite backup、整合性/ファイルSHA検証、最後の保存先切替。失敗時も元データを保持。
- 同一検索のページ移動で順位計算を再利用。上位1000件と60件ページング、遅延サムネイルを維持。
- 標準NSISのOS/x64案内、導入容量・WebView2案内、実行中アプリの更新/削除拒否。モデル・ユーザーデータを同梱しません。

## 確認済みの範囲

Windows 11 x64 / RTX 2070、同梱Python Worker、実WebView2、隔離データによる機能・導入試験です。詳細な成功/失敗と未検証は[検証記録](RELEASE_V1_VALIDATION.md)を参照してください。開発ツールがないクリーンWindowsの代用とはしません。

## 更新と削除

トレイで完全終了してからセットアップを実行します。写真・モデル・検索データは保持します。[利用ガイド](USER_GUIDE.md)に初回設定、更新、削除、復旧の手順があります。

[配布監査](DISTRIBUTION_AUDIT.md)のnative DLL配布条件、クリーンWindows/不足WebView2、実スリープ・再起動・実ドライブ切断の確認が残ります。未署名、自動更新なし、他GPU/Windows 10実機は未検証です。10万件検索は合成データ測定で初回約6秒。近似検索は未導入です。数千の異なる実写真・数時間以上の運転は今回測定していません。音声・動画・クラウド検索は未追加です。
