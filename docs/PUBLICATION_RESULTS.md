# GitHub初回公開の準備結果

2026-10-10。既存v1.0.0（459ce36）を保持し、公開資料と署名付きUpdaterのみを追加。写真検索エンジン、モデル、SQLiteスキーマ、Workerバイナリは変更していません。

## ソースとライセンス

元のGit履歴468 blobを対象パターンで検査し、トークン・秘密鍵・モデル/写真/DB/実行ファイルの混入は見つかりませんでした。これは未知の秘密情報すべての不存在保証ではありません。作者の個人用メールは含まれるため、元の履歴を保持して別の公開履歴を作成します。開発記録内のプロジェクト絶対パスは公開コピーで一般化します。

独自コードはApache-2.0へ変更し、PSF派生のexact_dot.c、第三者ソース、モデルの条件を区別しました。既存の第三者通知は維持。追加した公式UpdaterのWindows依存についてのみ通知を収集し、実際のWindows Cargoグラフ287パッケージに対する通知の欠落0を確認しました。既存native wheel監査を包括的にやり直していません。

README、人工画像の実UI例、貢献/行動指針/非公開脆弱性報告、Issue/PRテンプレートを整備。軽量Windows CIは読み取り専用で、モデル/GPU/インストーラー生成/自動公開を行いません。

## Updater

公式tauri-plugin-updater 2.13.2。公開鍵を固定し、GitHub Releasesのlatest.jsonをHTTPSで取得。起動時チェックは設定でOFFにでき、取得・導入は利用者が確認した場合だけです。写真・検索語は送信しません。失敗時は手動更新を案内します。

取得と署名検証の後、Workerにshutdownを送り、終了を確認してからインストーラーを起動します。終了確認が時間内に終わらなければ更新を中止します。NSISは/UPDATEの場合だけ親アプリの終了を最大10秒待ち、まだ実行中なら拒否します。既存の手動更新時の即時拒否とRuntime同意は維持。更新時の容量案内による対話待ちは修正しました。

秘密鍵は暗号化し、パスワードはWindows CurrentUser DPAPIで保護したローカル無視領域に保管。所有者による別媒体へのバックアップは必要です。Windows Authenticode署名はありません。

## 必要な検証

- TypeScript型チェック・Viteビルド・Windows Rustチェック成功。
- 軽量安全性テスト9件成功（既存データではなく隔離fixture）。
- 実NSIS署名付き更新：隔離インストールでQA 1.0.0 → 1.0.1成功。1.0.1はテスト専用で公開しません。
- HTTP失敗の案内、不正署名の拒否（Worker停止より前）、更新確認設定の保存を確認。
- 人工画像4件のコピーDB：更新後のベクトル一致、SQLite integrity_check=ok。写真再解析なし。
- QA用HTTP設定は別設定ファイルだけで使用し、本番設定はHTTPS。正式成果物にQAエンドポイントを含めません。

クリーンWindows、実OSの再起動/スリープ、他GPUの動作は今回検証していません。既存の性能・AI検索結果の記録を再利用し、大量画像解析・性能再測定はしていません。
