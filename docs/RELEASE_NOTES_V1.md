# Local Photo Search v1.0.0

2026-10-10。写真検索アプリの正式版v1.0.0。無料・オープンソースで配布します。GitHub Releasesへの掲載は所有者の承認後に行います。

Local Photo Searchは、PC内の写真を日本語の説明や参照画像から探す無料のWindowsアプリです。Google EmbeddingGemma 2によるAI処理と検索データはローカルで扱います。写真・検索語をクラウドへ送信せず、元の写真を書き換えません。

## 主な機能

- JPEG / PNG / WebPのフォルダー登録、サブフォルダーと差分解析。
- 日本語検索、類似画像検索、ファイル名・形式・更新日フィルター。
- グリッド/リスト、ページ表示、プレビューとズーム、元ファイル/保存場所を開く。
- 解析の一時停止・再開、失敗一覧と再試行、許可した場合のトレイ常駐。
- 初回セットアップ、既存モデル指定/確認後の公式取得、GPU/CPU診断。
- 検索データの安全な保存先コピー移行、容量表示、キャッシュ管理、ライト/ダークテーマ。

dev.2では全順位の検索を保持し、後方ページやフィルターで上位1,000件に打ち切られる問題を修正しました。合成10万件・同じ実行環境の検索比較は6.91秒から1.34秒へ改善。実写真10万枚の解析速度を示す値ではありません。

## 動作環境と導入

初期サポート対象は **Windows 11 64bit**。GPUの確認済み構成は **RTX 2070 / VRAM 8GB** です。他GPUは未検証。CPUは4スレッドの診断と少数人工画像で確認済みですが、大量写真の実用速度は未評価です。Windows 10、ARM、32bitは初期サポート対象外です。

Python、Rust、Node.jsの開発環境は不要。WebView2とMicrosoft Visual C++ v14 x64が必要で、不足時にはMicrosoft公式方式で導入を案内します。Microsoft Runtimeは通信・更新・診断データの取り扱いを伴います。インストーラーの通知とMicrosoft利用条件を確認してください。

AIモデル約462MiBは別途指定または確認後に取得します。保存先はモデル・検索データ・AIキャッシュ最大1GiB・サムネイル最大512MiBを考慮し、2GiB以上の空きを推奨します。写真本体の容量は別です。導入から検索までの詳しい手順は [ユーザーガイド](USER_GUIDE.md)。

## 更新とアンインストール

トレイから完全終了し、新しいセットアップを同じインストール先へ実行してください。実行中の更新は拒否します。設定・検索データ・モデル・元写真は保持します。失敗時は完全終了を確認して再実行してください。設定から署名付き更新を確認できます。ダウンロードと導入は利用者の確認後に行います。手動更新も利用できます。

Windowsの設定からアプリを削除できます。元写真とユーザーデータは削除しません。再インストールで既存データを再利用できます。データを整理する場合は保存場所を確認し、完全終了後に利用者自身で行ってください。

## 既知の制限と公開準備

検索類似度は正解率ではなく、人物識別・文字の完全一致を保証しません。動画・音声検索は今回含みません。次の開発は音声検索を予定しています。OSのスリープ/再起動、実トレイ操作、クリーンWindowsの導入は受入確認が残ります。未署名の実行ファイルとインストーラーにはSmartScreen警告が出る場合があります。

第三者の権利・全文はインストール先の `THIRD_PARTY_NOTICES.md` と `licenses/` に収録します。アプリ本体は無料・オープンソースです。独自コードはApache-2.0、第三者部分は元の条件を維持します。

将来はGitHub ReleasesでインストーラーとSHA-256を配布し、`videdegi.com` に紹介・使い方ページを設ける予定です。リポジトリ作成、Push、Web公開、公開日の確定は行っていません。

## GitHub初回公開向けの整備

ソースコードをApache-2.0で公開し、Issues/PRを受け付けます。設定から署名付き更新の確認・変更内容の表示・確認後の取得/導入が可能です。起動時の確認は無効化できます。更新はWorkerの保存と終了を待ってから導入し、手動更新も維持します。GitHub Releasesへの公開は管理者の最終承認後です。
