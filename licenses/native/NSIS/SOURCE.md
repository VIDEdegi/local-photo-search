# NSIS 3.11

COPYING is copied verbatim from the actual bundled NSIS 3.11 tool package.
https://github.com/tauri-apps/binary-releases/releases/tag/nsis-3.11
https://nsis.sourceforge.io/License

The installed/generated stubs use NSIS' license terms; built-in plug-ins
use zlib/libpng. The full COPYING also retains the compression library
notices and LZMA/CPL linking exception. We have not modified those modules.
The installer script is project code; the exception permits linking a
script/installer without turning the application into a CPL derivative.
The exact embedded plug-in list is obtained from a real makensis compile,
not merely from includes in a script. The installer and generated
uninstall.exe are also recorded separately in the artifact manifest.
